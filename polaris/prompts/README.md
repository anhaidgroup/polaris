# prompts/

The paper's three prompts, one module per prompt:

- `column_expansion.py` — column name expansion (Table 4)
- `table_expansion.py` — table name expansion (Table 5)
- `description_generation.py` — description generation (Table 6)

The embedded prompt builders are byte-for-byte copies of the paper's
prompt code — do not edit them.

`prompt_examples/` holds one real rendered prompt of each type, built
from an aw table.
